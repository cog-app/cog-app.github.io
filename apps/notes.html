Notes

The Notes app provides markdown note-taking with notebooks and tags.

Features

  • Markdown editing -- write notes in GitHub-Flavored Markdown
  • Notebooks -- organize notes into logical groups
  • Tags -- label notes for filtering and discovery
  • Archive -- archive notes you want to keep but hide from the main view
  • Autosave -- notes save automatically as you type

Editing

The editor supports standard Markdown with:

  • Headings, bold, italic, links, images
  • Code blocks with syntax highlighting
  • Lists (ordered and unordered)
  • Tables
  • Blockquotes

Sharing

Notes and notebooks can be shared with users or groups:

  • Read -- view the note
  • Write -- edit the note
  • Reshare -- manage sharing

Search

Notes are indexed for full-text search. Search matches against note titles, body text, and tags.
